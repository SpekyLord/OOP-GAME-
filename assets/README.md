# Assets (placeholders — art not made yet)

```
assets/
├── characters/
│   ├── male/    neutral.png, tired.png, stressed.png, recovered.png
│   └── female/  neutral.png, tired.png, stressed.png, recovered.png
├── backgrounds/ bedroom_day1.png ... bedroom_day5.png
├── items/       coffee.png, laptop.png, charger.png, notebook.png
└── ui/          sanity_bar.png, energy_bar.png, hunger_bar.png, hydration_bar.png (+ motivation)
```

The sprite file names match `Player.mood()` values. Sprites can be drawn in Piskel (piskelapp.com).
Ending splash arts (good / neutral / bad) can go in `backgrounds/` or a new `endings/` folder.
Until real art exists, the GUI can draw simple placeholder shapes.
